# Входящие файлы

Сюда вы кладёте всё, что хотите отдать агенту: выгрузки трекера, скриншоты, документы, ответы внешних сервисов.

**Как пользоваться:**

1. Скопируйте файл в эту папку — имя любое, понятное вам.
2. Скажите агенту: «файл в inbox, посмотри» (или назовите имя файла).
3. Агент прочитает только то, что вы разрешили, и только по вашему указанию.

**Правила:**

- Ничего не удаляйте и не переименовывайте после того, как агент начал разбор: он ссылается на файлы в своих записях.
- Если файл содержит имена, суммы, ключи — агент обезличит их перед записью в артефакты и запросы; но лучше не класть сюда секреты, которые не нужны для задачи.
- Содержимое этой папки не публикуется и не уходит наружу без вашего разрешения.

**Что будет дальше:** агент разберёт файл, запишет выводы в ваши рабочие файлы и назовёт один следующий шаг. Если файл не нужен — он так и скажет.
