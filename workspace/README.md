# workspace

Песочница для данных конкретного человека: профиль, карта деятельности, журнал циклов, заполненные шаблоны, собранные артефакты.

**Правила:**

- Это единственное место, куда агент пишет данные человека. В `templates/` он не пишет никогда.
- Содержимое папки не коммитится: в публичной истории остаётся только этот файл.
- Файлы отсюда не удаляются агентом без разрешения владельца.

С чего начинать: скопировать сюда шаблоны из `templates/` и заполнять копии, а не оригиналы.
