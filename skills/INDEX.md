# Реестр навыков

**Читается после `AGENTS.md` и `workspace/state.md`.** Это точка входа для агента: прежде чем что-то делать, найди в таблице триггер и загрузи один навык. Не нашёл триггер — не делай ничего, спроси человека.

**Как пользоваться.** Триггер совпал → открыть `skills/<имя>/SKILL.md` → работать по нему. Два навыка сразу не грузятся. Мета-навыки грузятся поверх шага, когда нужна их работа.

| Навык | Грузить, когда | Не грузить, когда | Артефакт на выходе | Дальше |
|---|---|---|---|---|
| `00-onboarding-interview` | новый человек; профиль устарел; советов про него нет | профиль и узкое место уже есть | `workspace/profile.md`, `workspace/activity-map.md` | `01` или `00b` |
| `00b-telemetry-setup` | о рутине отвечают «не знаю», «по-разному» | данные о времени есть | `workspace/time-log.md`, `workspace/file-log.md`, `workspace/tracker-export.md` | назад в `00` |
| `01-field-filter` | профиль есть, поля нет | поле выбрано и записано | `workspace/field-choice.md` | `02` |
| `02-hadi-hypothesis` | поле выбрано, гипотезы нет | гипотеза с критерием записана | `workspace/hadi-tracker.md` | `03` (внешний контур) |
| `03-prevalidation` | гипотеза с критерием готова, ответов извне нет | отчёт со ссылками уже разобран | отчёт с белыми пятнами | `04` |

| `07-conversation` | разговор назначен или только что прошёл | записи ещё нет, но и разговора нет | запись разговора с цитатами | `05` |

## Правила

1. **Реестр — не знание, а триггеры.** Что делать внутри шага, написано в самом навыке; реестр отвечает только на вопрос «какой навык сейчас».
2. **Один навык за раз.** Если совпали два триггера, порядок решает `m2-work-router`.
3. **Навык читается целиком перед работой**, а не по частям: у него есть стоп-условия и запреты в конце.
4. **Первый запуск** (нет `workspace/state.md`) всегда начинается с `00-onboarding-interview`: реестр читается, чтобы знать триггеры, но маршрут стартует с него, а не с реестра.
5. **Нет триггера — нет действия.** Агент не придумывает шаг, а спрашивает человека.
