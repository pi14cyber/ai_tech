# Архив запросов и ответов

Сюда переносятся пары «запрос + ответ», когда на все вопросы запроса получен ответ, и запросы, снятые с работы как неактуальные.

```
archive/
  req_00a_domains.md          запрос целиком, со строкой состояния
  answers/
    req_00a_domains.answer.md ответ на него
  req_01a_layers.md           снятый запрос: ответа нет и не будет
```

**Зачем переносить.** Активная папка должна показывать только то, что ещё ждёт ответа. Иначе через месяц непонятно, какие запросы отработаны, а какие висят.

**Что не теряется:**

- запрос и ответ лежат рядом, путь ответа виден в шапке запроса;
- проверки продолжают смотреть в архив: `verify_requests.py` проверяет структуру, `verify_research.py` — полноту;
- строка состояния в запросе остаётся с пометкой, сколько вопросов отвечено.

**Как переносить.** Вручную ничего не двигать:

```
python scripts/verify_state.py --move
```

Переносятся две категории:

1. **Отвеченные пары:** все блоки `### Q1.N` запроса имеют ответ, запрос и ответ ложатся рядом.
2. **Снятые запросы:** в шапке стоит `**Статус:** неактуален — причина`, ответа нет и не будет. Тема закрыта или поглощена другим запросом. Такой запрос тоже уходит в архив, но помечается «снят как неактуальный» и не считается недоделанным.

**Как проверить, что обе процедуры работают.**

```
python scripts/verify_state.py --self-test
```

Самопроверка строит временную папку и прогоняет оба случая: отвеченная пара должна уйти в архив с ответом рядом, снятый запрос — без ответа и с пометкой. Проверка самого проверяльщика — приём из `netresearch/agent-harness-skill`.
