## 1. Границы

- **Предмет:** источники, перечисленные в ответах предыдущей серии запросов на источники (лежат в архиве ответов) без адресов (arXiv-ID вида 26xx, «ФРС SR 26-2», названия стандартов и отчётов).
- **География и период:** публикации 2018–2026, язык английский; официальные сайты организаций предпочтительнее пересказов.
- **Что не спрашиваем:** оценки, мнения, прогнозы, код, пересказ содержания. Только адрес, название, дата, статус существования.

## 3. Контракт формата

1. **Нет адреса — нет ответа по источнику.** Каждая строка: идентификатор → URL или «не существует» / «не найдено».
2. **Запрет прогнозов и пересказов.** Только адрес, название, дата, статус.
3. **Микро-факт вместо обобщения:** URL страницы, а не «сайт организации»; дата версии, а не «недавно».
4. **Пропущенный идентификатор считается неотвеченным.**
5. Последняя строка ответа: «Чего найти не удалось: …».
6. **Без кода.** Код, псевдокод и «пример реализации» не нужны; если страница содержит код — нужен адрес страницы, а не копия.

## 4. Структура ответа

```markdown
### Q1.1. Название вопроса

- **Источники (ссылка + дата):**
- **Что говорит источник:**
- **Алгоритм словами:**
- **Критерии применимости / ограничения:**
- **Белые пятна:**
```

В конце ответа — таблица покрытия: идентификатор, статус (отвечено / белое пятно), число адресов.

## 5. Белые пятна

Белым пятном считается только то, что искали задокументированно: каналы, формулировки, проверенные реестры, дата. «Не нашлось» без описания поиска белым пятном не считается.

## 6. Параллельные каналы

Короткий запрос уходит в один канал. Если адреса подтвердятся частично и цена следующего шага высока — добирается полным запросом по шаблону `templates/request-full.md`.
