### 4.1. Можно ли теперь технически пройти маршрут, не пройдя предвалидацию

**Да.** Изменилось одно: у ворот появился адрес и форма, поэтому молчание больше не выглядит как «пройдено» — теперь нужно либо назвать путь, либо соврать про факты. Проверки по-прежнему нет ни на одном шаге:

1. **Файл.** `04:19` требует файл, но исполняемое правило говорит о фактах (`04:23`, `04:79`). Первым действием сборки проверка файла не стоит: порядок (`04:58-65`) начинается с получателя.
2. **Поле.** В состоянии есть только адрес с заглушкой `<дата>` (`state:56`), а не значение «пройдены / не пройдены / дата». Роутер выбирает ветку «предвалидация пройдена» (`m2:38`), но критерия содержания не задаёт, а его же правило — «существующий файл не доказывает, что этап закрыт» (`m2:25`).
3. **Проверка.** Ни один скрипт не читает `workspace/`: `verify_docs.py:36` пропускает `workspace/` целиком, `verify.py:67` читает только `LOCAL-ONLY`, `verify_consistency.py` смотрит шаблоны, числа и блоки состояния (`:39`, `:112-131`). Прогон на текущем дереве: код 0, одиннадцать строк «сходится». Отчёт ворот при этом просит вписать код проверки, который в пользовательском режиме означает «проверять нечего» (`rep:32`, `verify_research.py:83`).
4. **Три штатных обхода.** (а) Написать отчёт с одной ссылкой — критерий `03:104` ниже потребности артефакта. (б) Объявить внутренний контур — `state:8`, `04:23`; в `03` контура нет, обратной проверки нет. (в) Включить `LOCAL-ONLY` — ворота законно заменяются `[допущение]` (`AGENTS.md:209`, `03:98`), а `04` не говорит, что делать с артефактом в этом случае: стоп-4 покрывает только «фактов нет».

**Чего не хватает, чтобы ворота стали техническими:** поле исхода в `state` с датой и значением; в `04` — проверка существования файла по адресу, а не «фактов»; проверка в `verify_consistency.py`: файл по адресу из состояния существует, в нём отмечен исход, есть ссылка и дата, и для внешнего контура отчёт есть до артефакта. Сейчас есть форма и адрес, но нет ни поля со значением, ни проверки — то есть ворота остаются барьером для честного агента, а не для маршрута.
