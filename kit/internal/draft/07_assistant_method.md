# Методика персонального помощника — перенесена

Содержимое этого файла целиком вошло в публичную теорию: **`METHODOLOGY.md`** в корне репозитория.

Логика переноса: продукт обещает методику, а её нельзя было прочитать в одном месте. Теперь так:

| Что было здесь | Куда переехало |
|---|---|
| Входные данные, образ результата | `METHODOLOGY.md`, начало |
| Гарантии, инверсия интервью, принципы | `METHODOLOGY.md`, разделы 1–3 |
| Протокол интервью, вопросы, стоп-условия, чекпоинт | `METHODOLOGY.md`, раздел 4 |
| Три выхода интервью | `METHODOLOGY.md`, раздел 5 |
| Работа по пайплайну, роли, метрики, барьеры, чек-лист | `METHODOLOGY.md`, разделы 6, 12, 14–16 |
| Цепочка проверки, предвалидация | `METHODOLOGY.md`, разделы 7–8 |
| Нулевой цикл, сила сигнала, гейт доказательств | `METHODOLOGY.md`, разделы 9–10 |
| HADI при создании продукта | `METHODOLOGY.md`, раздел 6 (формула и норма) |
| Правило записи файлов и приёмка | `AGENTS.md`, разделы 13 и «Правило записи файлов» |

**Двух версий одного текста быть не должно.** Правки методики вносятся в `METHODOLOGY.md`; здесь остаётся только эта карта переноса, чтобы ссылки из истории проекта не вели в пустоту.
