## Главный вывод

Машина закрыла класс «пустой файл с правильным именем»: подсказка больше не считается ответом, ворота без двух фактов и файлов ответов не проходят, решение судьи без цитаты и версии не проходит, журнал с недопустимым классом и «проверено» без автора не проходит. Барьеров, которые держатся, всё ещё ноль — но у 8 из 21 появился машинный крючок, и **5 обходов круга 4 закрыто** (2, 7, 18, 19, 20).

Остались две группы.

**Первая — ложные входы.** Решение и «готов к показу» ставит проверяемый; версия не связана с артефактом; отчёт судьи и состояние читаются порознь. Пока это так, независимость судьи остаётся текстом.

**Вторая — одиночные обходы**, найденные каждым аудитором: два поля «Исход ворот» (первое побеждает), строка журнала без номера пропускается, пустая находка класса A без адреса, статус с заглавной буквы, меню вместо значения в шаге, «заблокировано» не мешало сборке, документы `workspace/artifacts/` не читаются, «решение „показывать“ в состоянии против „не показывать“ в отчёте» проходило.

## Что исправлено по итогам круга (v0.7–v0.9)

- Подсказка в поле не ответ; меню «a / b» не ответ; согласие о данных — строго одно из четырёх значений.
- Ворота: два факта (Q + адрес + дата в любом порядке), непустые файлы ответов, «дип» — по полю категории, а не по слову в шапке.
- Артефакт при заблокированных воротах запрещён; статус читается из поля, а не из легенды; заглавная буква в статусе — нарушение.
- Решение и версия отчёта судьи сверяются с состоянием; у отчёта судьи должна быть заполненная строка результатов.
- Журнал: строка без номера — нарушение; класс A/B без адреса — нарушение; «проверено» без автора — нарушение.
- Канон: точный список проверок (подмена скрипта не проходит), заглушки, пределы в контексте («четыре часа», «80 слов»), каждый предел обязан быть в `limits_where`, пустые группы запретов, дубли ключей убраны.
- Песочница: `runs/` без `self-01` — код 2, а не «нечего проверять»; 14-я проверка сверяет копию с репозиторием.
- `state.md`: «Решение человека» (цитата, канал, дата), «Номер сессии», «Готов к показу», «Статус» артефакта; счётчик сверяется с пределом по номеру сессии.
- Ветвь «сервиса нет» больше не петля: исполнение человеком или решение о переходе во внутренний контур.
- Ложный 16+ убран из карточки канона; в навыке 07 и словаре разделены «уже потраченное время» (8–15) и «новое вложение после разговора» (16+).
