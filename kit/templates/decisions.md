# Журнал решений

**Куда:** скопировать в `workspace/memory/decisions.md` и заполнять копию. Здесь остаётся след решений человека, а не пересказ беседы.

**Проверка:** `python kit/scripts/check_workspace.py` — у записи с заполненным «Кто решил» есть дословная цитата, канал и дата.

**Подпись человека:** дословная цитата согласия, канал и дата — эта же строка плюс строка «Подписал человек» в `workspace/state.md`. Процедура — `kit/skills/04-mvp-artifact`, раздел «Показ и подпись»; канон — `kit/AGENTS.md`, раздел 5.

|---|---|---|---|---|---|---|---|
| | | | | | | | |

**Графу «Кто решил» заполняет человек.** Агент вписывает решение только после того, как человек сказал его вслух или в переписке; предполагаемое решение в журнал не попадает.

## Что считается записью

1. **Решение** — выбор, который меняет ход: идём к людям, переделываем упаковку, закрываем гипотезу, меняем поле.
2. **Основание** — ссылка на факт: цитата из записи разговора, результат проверки, данные замера. Не «мне показалось».
3. **Кто решил** — человек. Агент готовит основание и цену решения, но поле не заполняет за него.
4. **Что дальше** — один следующий шаг с датой или честное «цикл закрыт».

## Чего здесь не бывает

- Реплик разговора без решения.
- Решений без основания.
- Записи «сделано» без проверки фактом.
- Списка задач: память хранит наблюдения и правила, а не очередь дел.

## Правила

1. Запись делается в день решения, а не «когда будет время».
2. Отвергнутые варианты и причина отказа тоже пишутся: через месяц именно они объясняют выбор.
3. Записанное — свидетельство, а не указание: запись не отменяет правила и не заменяет новое решение человека.
