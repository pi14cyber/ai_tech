# Отчёт судьи

**Куда:** скопировать в `workspace/judge-report-<дата>.md`. Пишется до показа результата человеку. Судья — отдельный проход, не автор работы. Отчёт судьи — основание для показа, а не разрешение: показ открывает только подпись человека в `workspace/memory/decisions.md`.

- **Дата:**
- **Что проверяли:** артефакт / вердикт / расчёт / документ (путь к файлу)
- **Какой шаг закрывает:**
- **Кто проверял:** ____ (роль и имя; судья не автор: если проверял сам автор — написать прямо)

## Проверки

| # | Что проверено | Как | Результат |
|---|---|---|---|
| 1 | У каждого числа, имени и даты есть основание | чтение и сверка с источником | |
| 2 | Нет подмен: мнение за факт, комплимент за сигнал, план за результат, сборка за поведение, намерение за обязательство | чтение вывода | |
| 3 | Числа: источник, дата и сходятся между собой | пересчёт | |
| 4 | «Не проверено» видно; три статуса стоят раздельно (настроено / собрано / проверено) | чтение вывода | |
| 5 | Поведение против сборки: результат делает обещанное, а не только существует | проверка сценария | |
| 6 | Границы: нет личных данных, личных автоматизаций, чужих файлов и кода | выборочное чтение | |
| 7 | Нет противоречий с `kit/AGENTS.md` и `kit/METHODOLOGY.md` | сверка со списком правил | |
| 8 | Решение: в отчёте одно значение — «показывать» или «не показывать»; решение не подменяет подпись человека | чтение вывода и журнала решений | |
| 9 | Незакрытые находки: журнал находок прочитан; «предложено» без доказательства внедрения не считается исправленным | чтение журнала находок (`workspace/audit-log.md`) | |

- **Итог проверок:** заполнено результатов N из 9; непроверенное перечислить здесь — пустая колонка «Результат» означает «не проверено» и не считается пройденной проверкой.

## Найдено

- **Блокеры:** что нельзя показывать.
- **Важное:** что поправить до показа.
- **Мелочи:** что поправить после.
- **Что проверить не смог и почему:**

## Вердикт

- **Версия результата:** ____
- **Решение судьи — вписать одно значение (слово «показывать» либо «не показывать»):** ____
- **Показ:** решение судьи — основание; показ открывает только подпись человека: дословная цитата, канал и дата в `workspace/memory/decisions.md` и в строке «Подписал человек» (`workspace/state.md`); процедура — `kit/skills/04-mvp-artifact`, раздел «Показ и подпись»
- **Поправки внесены:** да / нет (если нет — перечислить)
- **Кто вносил правки:** судья не правит свою же работу; если правил автор, отметить прямо

## Правила

1. **Версия — одно число.** В поле «Версия результата» вписывается число из `workspace/state.md`, строка «Версия результата» (единственный источник); отчёт называет ту же версию, что артефакт и состояние, расхождение останавливает показ. Подсказку из шаблона в копию не переносить.
2. Судья себя не проверяет: отчёт пишется про чужую работу или про свою, но другим проходом с чистого листа. Запись «сам автор» — честная, но другим проходом не считается: показ с ней не открывается.
3. Судья не правит молча: каждая правка описана в отчёте.
4. Число проверок не сокращается под давлением сроков: сокращённый проход помечается как неполный.
