# Внешние факты

Сюда попадают подтверждённые внешние данные со ссылками и датой: ставки и тарифы, состав рынка, существующие инструменты, отраслевые практики.

**Уровень:** `[внешнее]`. Это не валидация: планировать по этим данным можно, объявлять гипотезу верной нельзя.

**Срок годности обязателен.** Ставки, тарифы и состав рынка быстро устаревают: `freshness_ttl: 6m` или `12m`. Протухшую карточку скрипт проверки пометит, и по ней будет сформирован новый запрос исследователю.

**Откуда берутся.** Из ответов на запросы в `kit/internal/draft/requests/`: ответ разбирается, подтверждённые факты выжимаются в карточку по шаблону `kit/templates/knowledge-card.md`, карточка регистрируется в `kit/knowledge/INDEX.md`.
