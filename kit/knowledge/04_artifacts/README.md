# Эталоны артефактов

Обезличенные образцы того, что агент собирает человеку: аналитическая записка для эксперта, расчёт экономики процесса, структура брифа.

**Зачем.** Чтобы каждый раз не изобретать форму: человек получает каркас, а не пустой лист.

**Правило обезличивания:** в эталон попадает только структура и формулировки, без имён, цифр и фактов конкретного человека.
