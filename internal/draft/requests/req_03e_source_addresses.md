**Задача запроса:** найти релевантные источники и алгоритмы — **без кода**: дать проверяемые адреса (URL/DOI) и подтверждение существования для списка источников, названных в ответах `req_03a–req_03d`

> **Инструкция для исследователя.** Нужны **адреса и подтверждение существования** источников, названных в прошлых ответах. Никакого кода. Для каждого источника: полное название, тип (статья/стандарт/спецификация), URL или DOI, дата публикации (если есть) и дата проверки, что адрес открывается. Если источник не находится — написать «не найден» и указать, что именно проверяли. Список источников — в приложении к этому запросу.

## 1. Границы

- **Предмет:** 64 упоминания источников из ответов `req_03a`–`req_03d` (arXiv, NIST, ISO/IEC, RFC, FIPS, SR); список — в приложении ниже и в файле `internal/draft/responses/req_03_sources.md` у заказчика.
- **География и период:** глобально; проверка адресов на дату выполнения.
- **Что не спрашиваем:** оценки качества источников, прогнозы, сравнение заказчиков.

## 2. Вопросы

### Q1.1. Адреса источников из ответа req_03a (независимость судьи)

Для каждого источника из блока Q1.1–Q1.5 ответа `req_03a_judge_independence` дать URL/DOI, тип и подтверждение открытия. Отдельно — arXiv-идентификаторы: подтвердить, что статья с таким номером существует и её тема совпадает с заявленной.

### Q1.2. Адреса источников из ответа req_03b (происхождение и версии)

То же для `req_03b_provenance_versions`: стандарты происхождения, привязка версии к решению, неизменяемые журналы, словари статусов. Для стандартов — номер, редакция, официальный адрес.

### Q1.3. Адреса источников из ответа req_03c (шкалы доказательств)

То же для `req_03c_evidence_grading`: методологии оценки доказательств, пороги достаточности, критерий цены сигнала, слабые места шкал.

### Q1.4. Адреса источников из ответа req_03d (дизайн проверок)

То же для `req_03d_check_design`: самопроверка проверок, устойчивость к обходу, критерии остановки, слепые запросы, провалы аудитов.

### Q1.5. Проверка на вымысел

Для каждого источника отметить: «существует и тема совпадает» / «существует, но тема другая» / «не найден». Если источник выглядит вымышленным (номер arXiv не открывается, стандарта с таким номером нет) — написать прямо и указать, что проверяли.

## 3. Контракт формата

1. **Нет адреса — нет ответа по источнику.** Каждый источник — с URL/DOI или явным «не найден».
2. **Запрет прогнозов.**
3. **Микро-факты:** номер, редакция, дата публикации, дата проверки адреса.
4. **Пропущенный идентификатор считается неотвеченным.**
5. Последняя строка ответа: «Чего найти не удалось: …».
6. **Без кода.** Только адреса и подтверждения словами.

## 5. Белые пятна

Белое пятно подтверждается описанием поиска: каналы, формулировки, дата. «Не нашлось» без описания не считается.
