# Реестр запросов внешнему исследователю

## Правила

1. **Каждый запрос самостоятелен.** Отдельный файл, который уходит внешней модели без нас: внутри есть границы, контракт и структура ответа. Ссылок на другие запросы быть не может — соседей модель не увидит.
2. **Собран по шаблону:** `templates/request-short.md` (до пяти вопросов, один канал) или `templates/request-full.md` (до шести вопросов, минимум два канала).
3. **Своя нумерация** от `Q1.1` внутри файла, подряд, не больше шести вопросов. Ожидаемый ответ — до 2500 слов.
4. **Ответ** кладётся в `workspace/responses/<имя запроса>.answer.md` (для проектных запросов — в `internal/draft/responses/`).

Проверки:

```
python scripts/verify_requests.py   # структура и самостоятельность
python scripts/verify_research.py   # полнота ответов
```

## Как отправлять

Запросы независимы: можно отправлять параллельно и в любом порядке. Ответ приходит отдельным файлом на каждый запрос — один запрос, один ответ. Если сервис отвечает одним документом сразу на несколько запросов, ответ режется по файлам, содержимое дословное, нумерация приводится к нумерации запроса.
