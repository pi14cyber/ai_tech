# Реестр запросов внешнему исследователю

Все запросы нарезаны на пакеты. **Правило объёма:** один запрос — не больше шести вопросов, ориентир ожидаемого ответа — до 2500 слов. Причина инженерная: у внешней модели ограничены и бюджет поисковых шагов, и объём выдачи; на длинном списке она разбирает подробно первые вопросы, а хвост срезает, и проверка полноты такой ответ бракует.

Ответы складываются в `internal/draft/responses/` под тем же именем. Проверка:

```
python scripts/verify_research.py
```

## Как отправлять

1. Пакеты независимы: можно отправлять параллельно и в любом порядке, ответы сводятся по идентификаторам `Q`.
2. Формат ответа одинаковый, жёсткий блок разметки есть в каждом файле. Модель любит менять заголовки — синтаксис копируется символ в символ.
3. Пакет без ответа считается неотвеченным целиком: проверка идёт по каждому файлу отдельно.
4. Пользовательские запросы живут в `workspace/requests/`, здесь — только запросы самого проекта.
