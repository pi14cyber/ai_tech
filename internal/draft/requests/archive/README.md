# Архив запросов и ответов

Сюда переносятся пары «запрос + ответ», когда на все вопросы запроса получен ответ.

```
archive/
  req_00a_domains.md          запрос целиком, со строкой состояния
  answers/
    req_00a_domains.answer.md ответ на него
```

**Зачем переносить.** Активная папка должна показывать только то, что ещё ждёт ответа. Иначе через месяц непонятно, какие запросы отработаны, а какие висят.

**Что не теряется:**

- запрос и ответ лежат рядом, путь ответа виден в шапке запроса;
- проверки продолжают смотреть в архив: `verify_requests.py` проверяет структуру, `verify_research.py` — полноту;
- строка состояния в запросе остаётся с пометкой, сколько вопросов отвечено.

**Как переносить.** Вручную ничего не двигать:

```
python scripts/verify_state.py --move
```

Переносятся только те запросы, у которых все блоки `### Q1.N` имеют ответ.
