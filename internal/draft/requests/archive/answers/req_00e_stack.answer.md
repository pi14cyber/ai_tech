### Q1.1. Протокол подключения инструментов

- **Факты за:**
  - Model Context Protocol стандартизует обмен данными между агентами и внешними ресурсами: локальные файлы, базы данных, программные интерфейсы. Предоставляет инструменты, ресурсы, шаблоны и логирование (AAIF Blog, 2026).
  - Спецификация разделяет две редакции: Legacy (2025-11-25 и ранее) с установлением сессии через handshake initialize и Modern (2026-07-28) — переход на stateless-архитектуру без сессий на уровне протокола, метаданные в `_meta` каждого запроса, метод `server/discover` (MCP Versioning Spec, 28.07.2026; WorkOS, 2026).
- **Факты против:**
  - Архитектурный разбор Matt Mochalkin (Medium, 25.04.2026): фрагментированная экосистема непроверенных реестров превратила протокол в вектор системной компрометации.
  - Отчёт Akamai Security Research (2026): переход спецификации 2026-07-28 на stateless-модель, фоновые асинхронные задачи и интерактивные интерфейсы переложил ответственность за границы безопасности на разработчиков; риски фишинга через доверенный интерфейс агента и обхода корпоративных политик.
  - Перегрузка контекста: пользователи локальных моделей при окне 80k токенов отказываются от загрузки сложных описаний инструментов в контекст в пользу вызова обычных скриптов командной строки с флагом `--help` по требованию (Хабр, 10.09.2026).
- **Белые пятна:**
  - Статистика доли компаний, мигрировавших со сессионной редакции 2025-11-25 на stateless-редакцию 2026-07-28 к октябрю 2026 года, не найдена.

### Q1.2. Другие открытые стандарты подключения

- **Факты за:**
  - `AGENTS.md` (agents.md, репозиторий `agentsmd/agents.md`): открытый стандарт инструкций проекта для кодинг-агентов, принят более чем в 20 000 репозиториев к августу 2025 года; поддерживает вложенные файлы в монорепозиториях (в основном репозитории OpenAI — 88 файлов). Поддерживают OpenAI Codex, Google Jules, GitHub Copilot, Cursor, Aider, RooCode, Zed (InfoQ, 08.2025; agentsmd.io).
  - Agent Skills (agentskills.io, 18.12.2025): стандарт модульных папок с файлом `SKILL.md`, более 26 платформ.
  - Model Context Protocol (modelcontextprotocol.io, редакция 28.07.2026): стандарт подключения внешних источников данных и инструментов.
  - Universal Tool Calling Protocol / Code-Mode (`github.com/universal-tool-calling-protocol/code-mode`): вызов инструментов через генерацию кода вместо наполнения контекста схемами JSON (Хабр, 10.09.2026).
- **Факты против:**
  - Стандарт `AGENTS.md` не заменяет контроль человека над бизнес-логикой и архитектурными целями (InfoQ).
  - Классический вызов инструментов раздувает системный промпт на машинах с ограниченной видеопамятью (Хабр, 10.09.2026).
- **Белые пятна:**
  - Единый стандарт синхронизации долговременной эпизодической памяти агента между разными клиентами командной строки к октябрю 2026 года не стандартизирован.

### Q1.3. Инструменты для локальной работы

- **Факты за:**
  - OpenCode: лицензия MIT, 172 198 звёзд на GitHub к июню 2026, поддержка 75+ провайдеров и локальных моделей; платная подписка $5–$10 в месяц (Morph, 09.06.2026; Kilo.ai, 2026).
  - Gemini CLI: лицензия Apache 2.0, бесплатный лимит 60 запросов в минуту и 1 000 в день на личном аккаунте, окно до 1M токенов (Morph, 09.06.2026; DeployHQ, 2026).
  - OpenAI Codex CLI: лицензия Apache 2.0, входит в подписки ChatGPT (от $8 в месяц) (The AI Career Lab, 08.2026).
  - Claude Code: проприетарный, бесплатного тарифа нет, входит в подписки Claude Pro ($20 в месяц) и Max (от $100) (Kilo.ai, 2026; GuruSup, 2026).
  - Требования к железу: локальные агентские связки с контекстом 256k запускают на видеокартах уровня RTX 4090 (24 ГБ) или RTX 5090 с 64 ГБ оперативной памяти; на 16 ГБ видеопамяти и 48 ГБ памяти идут квантованные модели с контекстом 80k (Хабр, 09.09.2026; Reddit r/LocalLLaMA, 29.04.2026).
- **Факты против:**
  - На домашнем оборудовании с 16–24 ГБ видеопамяти узкое место — объём под кэш контекста: свыше 100–150k токенов с агрессивным квантованием качество генерации деградирует; ускорители прошлых поколений не поддерживают современные форматы и вырезаны из актуального ПО (Хабр, 10.09.2026).
  - Терминальные агенты не заменяют редактор кода и требуют параллельной работы в нём (GuruSup, 2026).
- **Белые пятна:**
  - Стандартизированные замеры энергопотребления и деградации накопителей при круглосуточной работе локальных агентов на потребительских ноутбуках не опубликованы.

### Q1.4. Память и контекст

- **Факты за:**
  - `AGENTS.md` реализует постоянную память проекта через плоские файлы Markdown в корне и подпапках: агент читает ближайший в дереве файл (agents.md).
  - Прогрессивное раскрытие в Agent Skills удерживает в постоянной памяти только метаданные (около 100 токенов), подгружая инструкции и справочные файлы с диска в момент активации задачи (agentskills.io; Agentman.ai).
  - Инструменты с окном 200K–1M токенов (Gemini CLI, Claude Code) загружают кодовую базу напрямую в контекст сессии без промежуточной векторной базы (DeployHQ, 2026).
- **Факты против:**
  - Хранение всех описаний инструментов и истории в системном промпте исчерпывает лимит памяти локальных машин (80k токенов при квантованном кэше) и снижает точность на длинных дистанциях (100–150k токенов) (Хабр, 10.09.2026).
  - Без модульной файловой структуры копирование инструкций между проектами приводит к рассинхронизации и дубликатам вручную (Dev.to, 2026).
- **Белые пятна:**
  - Независимые бенчмарки, сравнивающие точность агентского поиска по плоским индексам Markdown против локальных векторных баз, специально на задачах ведения проектной документации, не обнаружены.
