## Правила исполнителя

1. Правки только в публичном слое: `scripts/`, `rules/canon.json`, `skills/`, `templates/`, `AGENTS.md`, `START.md`, `METHODOLOGY.md`, `GLOSSARY.md`, `README.md`, `CHANGELOG.md`.
2. `internal/` — материалы проекта, читать можно, править только по прямому указанию в заказе.
3. После каждой пачки: `python scripts/verify.py` должен вернуть код 0.
4. После правок публичного слоя пересобрать песочницу `runs/self-01` (копия файлов и папок; правило в `AGENTS.md` §13, проверка `scripts/verify_sandbox.py`) — иначе приёмка красная.
5. Каждое исправление сопровождается пробой: фикстура → ожидаемый код. Без пробы заказ не считается выполненным.
6. Изменения коммитить по одному заказу, сообщение — что и зачем. Не переписывать чужие коммиты.
7. Вернуть: краткий отчёт «задача → что изменено → файл:строка → проба → код», плюс `git log --oneline` за пачку.
