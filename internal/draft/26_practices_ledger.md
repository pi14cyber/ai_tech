## 3. Ждёт владельца (правки в `templates/`)

1. `templates/hadi-tracker.md` — поля для ответа человека и срока, статусы обязательств, запрет считать молчание выполнением.
2. `templates/request-short.md` и `templates/request-full.md` — строка «Категория: быстрая / дип».
3. `templates/research-response.md` — таблицу покрытия считает скрипт, а не исследователь; к каждому факту адрес, дата и признак свежести.

## 4. Отклонено — с причиной

| Что | Откуда | Почему |
|---|---|---|
| Автономный агент с песочницей, сам ставит пакеты и собирает себя | `tooling-orchestration` | ответственность уходит от человека |
| «Невидимая безопасность», исход USE_DEFAULT как успех | `tooling-orchestration` | сбой выхода нельзя выдавать за успешный прогон |
| Полный захват экрана и звука по умолчанию | `tooling-memory-tasks` | против презумпции приватности |
| Отчёт о действии, которого не было; выдуманное поле ради формы | `tooling-memory-tasks` | обман в отчёте ломает доверие ко всем отчётам |
| Беседа как память проекта; состояние только в памяти вкладки | `tooling-memory-tasks` | в записи нет решения, основания и отвергнутых вариантов |
| Телеметрия по умолчанию | `tooling-memory-tasks` | внешний запрос — решение человека |
| Автоматизация с правом писать в чужие сервисы | `tooling-memory-tasks` | такого класса действий у нас нет |
| Оценка риска действия моделью | `tooling-agents` | ИИ не валидирует |
| Пентест, SARIF, облачные панели | `tooling-verification` | инструмент нападения, не наш шаг |
| Граф знаний, tree-sitter, 24 языка | `tooling-verification` | набор превращается в каталог |
| Awesome-списки как материал набора | `tooling-verification`, `tooling-catalogs` | каталог противоречит критерию «снижать стоимость шага» |

| Резидентный сервис и 2 ГБ моделей, облачный разбор по умолчанию, MCP-серверы без аутентификации | `tooling-documents` | тяжело, дорого или небезопасно |
| Числовые рейтинги журналов и контента, SHA-256 на каждую загрузку, SQLCipher | `tooling-personal` | сложность без шага маршрута |
| Автосжатие контекста (первое прочтение README) | `tooling-agents` | отклонено вторым разбором: наша сессия ограничена вопросами, а не контекстом |

## 5. Что дал разбор помимо практик

- **Проверка заявлений владельца.** Из девятнадцати проверенных утверждений списка **не подтвердились четыре**: докачка в `pdf2md-mcp`, иерархия заголовков `docling` по умолчанию, «более 20 источников» у `gpt-researcher`, «диалоговый интерфейс вместо карточек» у `taskosaur`. Ещё шесть подтвердились частично (числа из собственных бенчмарков, «лёгкость» утилит, зависимости от режима).
- **Внешний список остаётся `[внешнее, без ссылок]`**: работали по файлам клонов, а не по описаниям.
- **Уроки субагентов о собственных ошибках:** три перепутанных факта нашлись при скептическом проходе, шесть — у группы оркестрации. Машинная проверка ссылок этого не ловит, и это записано в отчётах.
