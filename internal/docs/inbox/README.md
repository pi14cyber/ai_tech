# inbox

Сюда кладутся новые источники: книга, статья, ссылка, выгрузка. Агент читает файл, выжимает из него карточку по шаблону `templates/knowledge-card.md`, регистрирует её в `knowledge/INDEX.md`, а оригинал оставляет в разделе источников.

**Что считается обработанным:** карточка создана, зарегистрирована в индексе, `python scripts/verify_knowledge.py` даёт код 0, оригинал перенесён в `internal/docs/biblio/` (текст) или `internal/docs/biblio/pdf/` (оригинал).

**Правило:** источник без карточки считается необработанным. Свалка файлов без выжимок базой знаний не является.
