# Стартовая точка: ИИ в вашей работе

Рабочее название, финальное ещё не выбрано.

Набор навыков и шаблонов для вашего ИИ-агента. Сначала агент интервьюирует вас как основатель пользователя: пять вопросов, по одному. Из ответов собирается профиль, находится одно узкое место и появляется первый артефакт, который можно показать живому человеку. Дальше агент ведёт вас по маршруту и не даёт объявить работу сделанной, пока результат не проверен на людях.

## Зачем это вам

1. **Вход без изучения инструментов.** Не нужно разбираться в моделях и промптах: пять вопросов, первый артефакт в пределах пятнадцати минут.
2. **Промпты писать не надо.** Агент сам задаёт вопросы, показывает выводы на подтверждение и ведёт файлы. Вы выбираете и подтверждаете.
3. **Защита от самообмана.** Агент не принимает ваше мнение за доказательство и не объявляет результат готовым без контакта с человеком. Это главная ценность: без неё ИИ просто ускоряет движение не туда.
4. **Всё остаётся в файлах.** Профиль, гипотезы, артефакты и выводы накапливаются. Через месяц вы видите не «я думал про рынок», а конкретную гипотезу, критерий и результат.
5. **По-русски.**

## С чего начать

Скажите своему агенту:

> Прочитай `AGENTS.md` в этом репозитории и запусти `00-start-here`.

Если агент не умеет читать репозиторий, склонируйте его и откройте в редакторе:

```
git clone <адрес этого репозитория>
```

Дальше агент задаст первый вопрос. Отвечать можно коротко, своими словами, голосом или одним словом.

## Что внутри

| Элемент | Назначение |
|---|---|
| `AGENTS.md` | правила: состояние прежде совета, уровни доказательности, кому адресуется вопрос, форма вопросов |
| `skills/00-start-here` | первое интервью: пять вопросов, профиль, узкое место, первая гипотеза |
| `templates/profile.md` | шаблон профиля, который заполняет агент |
| `pres/` | материалы, из которых собрана методика: конспекты книг с цитатами, черновик выступления, методология |

Остальные навыки маршрута — выбор поля, гипотезы, артефакт, доступ, разговор, решение — в работе.

## Чего этот набор не делает

- Не валидирует вашу идею: это делают только живые люди.
- Не заменяет разговор: агент готовит повод и разбирает итог, но разговариваете вы.
- Не выбирает за вас поле и не принимает решений.
- Не гарантирует деньги: он сокращает путь до проверки, а не заменяет её.

## На чём это построено

Метод собран из книг, которые лежат в репозитории с цитатами и номерами строк:

- Питер Тиль, «От нуля к единице» — почему конкуренция разрушает прибыль.
- Стив Бланк, «Четыре шага к озарению» и «Стартовая книга основателя» (с Бобом Дорфом) — как проверять гипотезы на живых людях.
- Роб Фитцпатрик, «Спроси маму» — почему комплименты бесполезны и что считать обязательством.
- HADI-циклы — дисциплина проверки: гипотеза, действие, данные, вывод.

Устройство набора — по образцу открытого проекта [gtm-cofounder](https://github.com/AIDevGTM/gtm-cofounder) (лицензия MIT), который лежит здесь сабмодулем как источник формы.

## Статус

В работе. Готовы: правила репозитория, первое интервью, шаблон профиля, методология и конспекты источников. В работе: остальные навыки маршрута, шаблоны артефактов, контролёр валидации.
