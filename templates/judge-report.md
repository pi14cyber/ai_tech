# Отчёт судьи

**Куда:** скопировать в `workspace/judge-report-<дата>.md`. Пишется до показа результата человеку. Судья — отдельный проход, не автор работы.

- **Дата:**
- **Что проверяли:** артефакт / вердикт / расчёт / документ (путь к файлу)
- **Какой шаг закрывает:**

## Проверки

| # | Что проверено | Как | Результат |
|---|---|---|---|
| 1 | Все числа имеют источник | пересчёт по файлам | |
| 2 | Каждая цитата дословна | сверка с записью | |
| 3 | Нет подмены «показано» на «доказано» | чтение вывода | |
| 4 | Нет «не проверено», выданного за проверенное | чтение вывода | |
| 5 | Термины употреблены в нашем значении | словарь | |
| 6 | Работа сделана до конца, а не до удобного места | чек-лист шага | |

## Найдено

- **Блокеры:** что нельзя показывать.
- **Важное:** что поправить до показа.
- **Мелочи:** что поправить после.
- **Что проверить не смог и почему:**

## Вердикт

- **Показывать / не показывать:**
- **Поправки внесены:** да / нет (если нет — перечислить)
- **Кто вносил правки:** судья не правит свою же работу; если правил автор, отметить прямо

## Правила

1. Судья себя не проверяет: отчёт пишется про чужую работу или про свою, но другим проходом с чистого листа.
2. Судья не правит молча: каждая правка описана в отчёте.
3. Число проверок не сокращается под давлением сроков: сокращённый проход помечается как неполный.
