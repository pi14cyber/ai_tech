# Отчёт судьи

**Куда:** скопировать в `workspace/judge-report-<дата>.md`. Пишется до показа результата человеку. Судья — отдельный проход, не автор работы.

- **Дата:**
- **Что проверяли:** артефакт / вердикт / расчёт / документ (путь к файлу)
- **Какой шаг закрывает:**
- **Кто проверял:** отдельный проход; если проверял сам автор — отметить прямо и перечитать с чистого листа

## Проверки

| # | Что проверено | Как | Результат |
|---|---|---|---|
| 1 | У каждого числа, имени и даты есть основание | чтение и сверка с источником | |
| 2 | Нет подмен: мнение за факт, комплимент за сигнал, план за результат, сборка за поведение, намерение за обязательство | чтение вывода | |
| 3 | Числа: источник, дата и сходятся между собой | пересчёт | |
| 4 | «Не проверено» видно; три статуса стоят раздельно (настроено / собрано / проверено) | чтение вывода | |
| 5 | Поведение против сборки: результат делает обещанное, а не только существует | проверка сценария | |
| 6 | Границы: нет личных данных, личных автоматизаций, чужих файлов и кода | выборочное чтение | |
| 7 | Нет противоречий с `AGENTS.md` и `METHODOLOGY.md` | сверка со списком правил | |

## Найдено

- **Блокеры:** что нельзя показывать.
- **Важное:** что поправить до показа.
- **Мелочи:** что поправить после.
- **Что проверить не смог и почему:**

## Вердикт

- **Версия результата, к которой относится отчёт:** (файл и дата; отчёт без привязки к версии не засчитывается)
- **Решение судьи — вписать одно значение (слово «показывать» либо «не показывать»):** ____
- **Поправки внесены:** да / нет (если нет — перечислить)
- **Кто вносил правки:** судья не правит свою же работу; если правил автор, отметить прямо

## Правила

1. Судья себя не проверяет: отчёт пишется про чужую работу или про свою, но другим проходом с чистого листа.
2. Судья не правит молча: каждая правка описана в отчёте.
3. Число проверок не сокращается под давлением сроков: сокращённый проход помечается как неполный.
