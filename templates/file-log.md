# Слепок рабочей папки (только метаданные)

**Куда:** скопировать в `workspace/file-log.md`. Заполняется скриптом или человеком по метаданным: даты, размеры, типы файлов, время правок. **Содержимое не читается.**

| День | Папка | Файлов | Типы файлов | Правок за день | Период активности |
|---|---|---|---|---|---|
| | | | | | |

## Что можно и чего нельзя

- **Можно:** количество файлов, расширения, даты создания и правок, длительность работы.
- **Нельзя:** открывать содержимое, читать текст, выгружать имена клиентов и проектов.
- Разрешение на чтение метаданных даётся отдельно и один раз; отказ ничего не блокирует.

## Критерий закрытия

Три-пять дней записей и хотя бы одна операция, у которой видно время. Иначе цикл закрывается как «данных нет».

## Правила

1. Это второй по приватности сборщик после микро-пингов: он предлагается, когда человек не готов отвечать сам.
2. Агент не запускает обход папок без явного разрешения.
3. Метка записей: `[validated: data]`.
