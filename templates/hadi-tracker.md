# Журнал циклов HADI

Каждая строка — один цикл проверки. Ведётся агентом, статусы меняет человек.

## Активные циклы

| # | Гипотеза (если…, то…, потому что…) | Действие | Что считаем данными | Критерий подтверждения | Статус | Вывод |
|---|---|---|---|---|---|---|
| 1 | | | | | черновик | |

## Статусы артефакта

`черновик` → `показан человеку` → `есть обязательство`

- `показан человеку` ставит только человек, с датой и указанием, кому показал.
- Пока статус `черновик`, агент не предлагает шаги вперёд, а предлагает показать.
- Обязательство: время, репутация, деньги, доступ к данным, назначенная встреча.
- Отсутствие обязательства — тоже результат: он ведёт к новой гипотезе.

## Закрытые циклы

| # | Гипотеза | Статус | Что узнали | Следующая гипотеза |
|---|---|---|---|---|
| | | подтверждена / отклонена | | |

## Правила ведения

1. Один цикл — одна переменная. Поменяли цену, текст и дизайн сразу — не узнаете, что сработало.
2. Спринт 1–2 недели. Дольше — значит действие было слишком большим.
3. Вывод пишется в день окончания цикла, а не «когда будет время».
4. Отрицательный результат фиксируется как знание, а не как провал.
