# Журнал циклов HADI

**Куда:** скопировать в `workspace/hadi-tracker.md` и заполнять копию. В `templates/` не писать.

**Проверка:** машинной проверки у формы нет: критерий подтверждения и статус сверяет человек перед гейтом `skills/05-validation-gate`.

Каждая строка — один цикл проверки. Ведётся агентом, статусы меняет человек.

## Активные циклы

| # | Гипотеза (если…, то…, потому что…) | Действие | Что считаем данными | Критерий подтверждения | Статус | Срок | Ответ человека | Вывод |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | | черновик | | | |

## Статусы обязательства

`открыто` → `ждёт` → `просрочено` → `нужна проверка`

- `открыто` — договорились, срок не наступил.
- `ждёт` — срок наступил, ответа нет. Молчание не значит выполнение.
- `просрочено` — срок прошёл, обязательство не выполнено: это результат и повод к новой гипотезе.
- `нужна проверка` — человек сказал, что сделано; проверяется фактом, а не словами.

**Колонки «Срок» и «Ответ человека».** Срок — дата закрытия цикла. Ответ человека заполняет только человек: идём дальше, переделываем упаковку или закрываем гипотезу. Пока поле пустое, цикл не закрыт, и агент не закрывает его сам.

## Статусы артефакта

`черновик` → `показан человеку` → `есть обязательство`

- `показан человеку` ставит только человек, с датой и указанием, кому показал.
- Пока статус `черновик`, агент не предлагает шаги вперёд, а предлагает показать.
- Обязательство 16+: новое время или деньги после разговора, репутация, доступ, интро к решающему; шкала — `templates/interview.md`; уже потраченное — 8–15, встреча — не обязательство.
- Отсутствие обязательства — тоже результат: он ведёт к новой гипотезе.

## Правила ведения

1. Один цикл — одна переменная. Поменяли цену, текст и дизайн сразу — не узнаете, что сработало.
2. Спринт 1–2 недели. Дольше — значит действие было слишком большим.
3. Вывод пишется в день окончания цикла, а не «когда будет время».
4. Отрицательный результат фиксируется как знание, а не как провал.
5. Молчание человека не считается выполнением: договорённость без подтверждения переходит в `просрочено`.
6. Решение человека записывается его словами и только им: агент поле не заполняет.

## Приоритизация (ICE)

Когда активных циклов больше одного, очередь задаётся не «что интереснее», а ICE: влияние (I), уверенность (C), простота (E) по шкале 1–10. Поля обязательные: без трёх чисел цикл не ставится в очередь.
