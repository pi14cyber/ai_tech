# Журнал находок

**Куда:** скопировать в `workspace/audit-log.md`. Одна строка — одна находка. Форма нужна, чтобы «предложил и забыл» не проходило.

| # | Дата | Что нашли | Класс | Где (файл:строка) | Статус | Доказательство внедрения | Кто решил | Кто проверил |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

**Классы доказательств:**
- **A** — наблюдал сам (файл, скриншот, запуск).
- **B** — сказал человек (цитата).
- **C** — вывод агента (может быть неверным).
- **D** — заявлено описанием (README, витрина, обзор), в файлах не проверял.

**Кто проверил:** находку подтверждает человек или отдельный проход судьи; агент, который её написал, своё же не подтверждает.

**Статусы:** `найдено` → `предложено` → `внедрено` / `отклонено` → `проверено`.

## Правило, ради которого журнал существует

**Предложенная правка не равна исправленному.** Пока в колонке «Доказательство внедрения» нет ссылки на изменённый файл и строку, находка открыта, даже если о ней договорились. Отклонённая находка остаётся в журнале с причиной: через месяц именно она объясняет, почему так не сделали.

## Правила

1. Класс ставится честно: вывод агента — это C, а не A.
2. Без адреса находка не считается: файл и строка либо цитата человека.
3. Одна строка — одна проверяемая претензия, не список.
4. Повтор одной и той же находки — повод переписать правило, а не повторить запись.
