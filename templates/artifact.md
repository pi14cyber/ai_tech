# Артефакт-предлог

**Куда:** скопировать в `workspace/artifact.md` и заполнять копию. Сборка — одна сессия, не дольше четырёх часов.

## Получатель и повод

- **Кто получатель:** роль, а не «эксперты вообще».
- **Что он должен увидеть:** одна фраза.
- **Какое решение принять после просмотра:** одна фраза.

## Содержание

- **2–3 факта из предвалидации, которых получатель не найдёт за минуту:** факт + ссылка + дата.
- **Белые пятна как повестка:** 3–5 вопросов, на которые ответить может только он.
- **Сознательная неполнота (примерно пятая часть):** что намеренно не доделано и почему именно это втянет его в соавторство.

## Ворота проверки до сборки

- **Что считаем готовым:** одна фраза.
- **Чем проверяем:** контрольный пример, сверка с источником, прочтение вслух.
- **Чего в артефакте быть не должно:** личные данные, чужие кейсы, обещания без основания.
- **Исходы:** прошло / провалилось / заблокировано / не запускалось. «Не запускалось» пишется прямо.

## Сообщение человеку

До 80 слов: кто я → почему я к вам → что принёс → один вопрос → просьба на 20 минут.

## Статус

| Артефакт | Статус | Кому показан | Дата | Обязательство |
|---|---|---|---|---|
| | черновик | | | |

Статусы: `черновик` → `показан человеку` → `есть обязательство`. Меняет человек.

## Правила

1. Таймбокс четыре часа; после второго круга переделок артефакт показывается как есть.
2. Артефакт открывает дверь, а не закрывает вопрос.
3. Личные автоматизации и реальные кейсы владельца в артефакт не попадают.
