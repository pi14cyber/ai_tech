# Замер рутины (микро-пинги)

**Куда:** скопировать в `workspace/time-log.md`. Самый приватный сборщик: в систему попадает только то, что человек сказал сам.

| День | Время | На что ушло | Сколько минут | Что мешало |
|---|---|---|---|---|
| | | | | |

**Формат ответа:** одна фраза два раза в день, «на что ушли последние три часа». Оценки на глаз заменяются фактом.

## Критерий закрытия цикла

Цикл закрыт успешно, если за 3–5 дней набралось минимум три дня записей и хотя бы одна операция с измеримым временем.

## Если человек сорвался

Два дня подряд без ответа → цикл закрывается досрочно, результат фиксируется как «данных нет», работа продолжается по памяти с пометкой `[assumption]`. Дожимать запрещено.

## Правила

1. Метка записей: `[validated: data]` — это факт о человеке, а не подтверждение рынка.
2. Данные не покидают машину и не публикуются.
3. Замер нужен один раз, чтобы найти узкое место; бесконечный сбор данных — это уже откладывание разговоров.
