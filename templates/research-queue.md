# Очередь заданий внешнему исследователю

Сюда попадают только те вопросы, на которые не может ответить человек и которые не закрываются книгами. То есть вопросы о внешних фактах: рынки, цифры, практики, инструменты.

Правило маршрутизации: ответ есть в базе — читаем базу; факт о человеке — спрашиваем человека; факт о мире — идёт сюда.

## Формат задания

```
### Задание N. Короткое название
Вопрос: что именно надо выяснить.
Зачем: на что это влияет.
Что считается ответом: критерий достаточности.
Канал: Perplexity / Qwen / Google / другой.
Статус: отправлено / получено / нужно уточнить.
```

## Формат находки

Каждая находка обязана содержать ссылку и дату обращения. Нет ссылки — нет находки.

```
- Дата: 2026-10-18
  Задание: N
  Ссылка: https://...
  Что установлено: одна-две фразы.
  Уровень: [внешнее]
```

## Напоминание

Уровень `[внешнее]` не является валидацией. Предвалидация отсеивает мёртвое и уточняет вопросы для разговора, но вердикт выносят живые люди.
