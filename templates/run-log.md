# Журнал прогона

**Куда:** скопировать в `workspace/run-log.md`. Заполняется по ходу прогона методики: по одной строке на шаг.

| Шаг | Дата | Время, мин | Что делали | Что пришлось объяснять | Где сорвалось | Запись в журнал находок |
|---|---|---|---|---|---|---|
| | | | | | | |

## Сводка по прогону

- Время до первого артефакта:
- Сколько вопросов до профиля:
- Где агент додумал за человека:
- Где спросили то, что можно прочитать:
- Число возвратов назад:
- Время на артефакт (факт против таймбокса 4 часа):
- Разговор состоялся: дата, кто, результат (обязательство / отказ / нет доказательств)
- Сколько дефектов протокола найдено:
- Три гипотезы о сорванных шагах, записанные до прогона, и что вышло:

## Правила

1. Журнал заполняется в день шага, а не в конце недели: память сглаживает срывы.
2. «Что пришлось объяснять» — цитата, а не пересказ: это дефект навыка, а не человека.
3. Комплименты и «понравилось» в результат не пишутся; результат — обязательство, отказ с причиной или честное «доказательств нет».
4. Каждый дефект уходит в журнал находок со ссылкой на файл и строку навыка.
