# Карта деятельности

Заполняется агентом по ответу на вопрос «что вы делали в прошлый вторник». Один реальный день, разложенный на операции. Человек подтверждает или правит.

## День

Дата или период: _____

| Операция | Частота | Длительность | Нужно суждение | Есть данные | Кандидат |
|---|---|---|---|---|---|
| | | | да / нет | да / нет | да / нет |

Пояснения к столбцам:

- **Операция** — простое действие: открыл, посмотрел, написал, посчитал, позвонил, отправил, согласовал.
- **Частота** — сколько раз в неделю повторяется.
- **Длительность** — сколько минут занимает один раз.
- **Нужно суждение** — требуется ли человеческая оценка или это формальность.
- **Есть данные** — доступны ли агенту входные материалы.

## Кандидаты на внедрение

Выбираются операции с высокой частотой, низкой ценностью суждения и доступными данными.

## Что не трогаем

- живые разговоры
- решения
- ответственность
