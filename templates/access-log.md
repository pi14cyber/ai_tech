# Журнал доступа

**Куда:** скопировать в `workspace/access-log.md`. Здесь считается работа по доступу к людям, а не знакомства «вообще».

| Неделя | Прикосновений | Ответов | Встреч | Канал | Что сработало |
|---|---|---|---|---|---|
| | | | | | |

**Счёт:** доля ответов = ответы / прикосновения; доля встреч = встречи / ответы; цена канала = потраченное время / встречи.

**Прикосновение** — одно обращение к человеку: сообщение, письмо, звонок. Разговор — это уже `workspace/interviews/`.

## Ритм

- Минимум десять прикосновений в неделю.
- Минимум один разговор с новым человеком в одну-две недели.
- Один канал за раз; смена канала — после двадцати прикосновений без ответов.

## Судьба одного контакта (правило тишины)

| Дата прикосновения | Кто | Канал | Ответ | Дата ответа | Напоминание (дата) | Отказ по молчанию (дата) |
|---|---|---|---|---|---|---|
| | | | | | | |

- За спринт — минимум три независимых контакта по одному и тому же поводу.
- Ответа нет 72 часа после одного напоминания → фиксируется **отказ по молчанию**: это результат про повод, а не про идею, и он разрешает пересобрать сообщение.
- Молчание не значит «подумает»: статус меняется по дате, а не по надежде.

## Правила

1. Счёт ведётся по факту, а не по ощущению: цифра из памяти не считается.
2. «Что сработало» заполняется одной фразой: что именно принесло ответ или встречу.
3. Никаких рассылок пачками: журнал создан, чтобы видеть, какой канал работает, а не чтобы увеличить число строк.
