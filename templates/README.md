# Шаблоны

Пустые формы, которые заполняются в `workspace/`. Агент **никогда не пишет в `templates/`**: он копирует нужный шаблон в `workspace/` и заполняет копию.

## Что здесь лежит

| Шаблон | Кто заполняет в основном | Куда копируется |
|---|---|---|
| `profile.md` | агент из базы и из ответов человека | `workspace/profile.md` |
| `state.md` | агент ведёт, статусы артефакта подтверждает человек | `workspace/state.md` |
| `activity-map.md` | агент по данным замера, человек подтверждает | `workspace/activity-map.md` |
| `assumptions.md` | агент предлагает, человек утверждает условие смерти | `workspace/assumptions.md` |
| `interview.md` | агент размечает после разговора | `workspace/interviews/` |
| `hadi-tracker.md` | агент ведёт, статусы меняет человек | `workspace/hadi-tracker.md` |
| `research-queue.md` | агент пишет задания, внешний исследователь приносит факты | `workspace/research-queue.md` |
| `source-conflicts.md` | агент | `internal/draft/` при работе с источниками |

## Разметка полей по заполняющему

Приём, которого нет у разобранных нами чужих наборов: **каждое поле помечается, кто его заполняет.** Это снимает главный вопрос человека «а что мне тут писать».

- `[человек]` — знает только он: личный опыт, доступы, границы, выбор.
- `[агент]` — выводится из базы и уже сказанного.
- `[внешний]` — приносит внешний исследователь со ссылкой и датой.
- `[замер]` — приходит из данных замера (нулевой цикл).

Если поле не помечено, шаблон считается недоделанным.

## Правила заполнения

1. Копия, а не оригинал. Правки только в `workspace/`.
2. Метка достоверности обязательна у каждого пункта: `[validated: data]`, `[validated]`, `[assumption]`.
3. Статусы меняет человек. Агент может предложить смену и привести основание.
4. Пустое поле лучше выдуманного: пустое видно, выдуманное нет.
