# Карта сети

**Куда:** скопировать в `workspace/network.md` и заполнять копию. Заполняется из ответов человека, а не чтением его переписки и папок.

**Проверка:** машинной проверки нет: карту сверяет человек, агент не сканирует контакты и переписку.

## Люди, которых человек знает лично

| Кто (роль, без лишних персональных данных) | Где познакомились | Чем может быть полезен | Последний контакт | Отрасль |
|---|---|---|---|---|
| | | | | |

## Вход в отрасли цели

| Отрасль | Кто из знакомых в ней | Кто может представить | Где человек бывает физически | Что делает публично |
|---|---|---|---|---|
| | | | | |

## Правила

1. Источник — ответы человека, дословно; агент не сканирует контакты и переписку.
2. Если человек дал явное разрешение, читаются только метаданные: кто, как часто, кто отвечает. Содержимое — нет.
3. Карта обновляется после каждого состоявшегося разговора, а не за один вечер.
4. Данные третьих лиц наружу не уходят: в публичные материалы имена не попадают.
