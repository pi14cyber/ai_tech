## Правила

1. Нет ссылки — нет находки: у каждого факта адрес и дата.
2. Белое пятно принимается только при задокументированном поиске: каналы, формулировки, дата.
3. Ответ без адресов — не факт, а повод повторить запрос.
4. Отчёт переживает сессию: по нему собирается артефакт и повестка разговора.
