# Состояние

Единая точка состояния. **Создаётся в шаге 0, до первого вопроса**, копией этого шаблона в `workspace/state.md`. Агент читает файл первым действием в любой новой сессии и обновляет до её конца. Без него маршрут не продолжается: следующая сессия снова начнёт с онбординга.

## Режим и контур

- **Режим:** обычный / только локально. Файл `workspace/LOCAL-ONLY` создаёт **человек**; агент режим не переключает, а сообщает текущее состояние.
- **Контур:** (вписывает ответ человека: внешний или внутренний; пусто = внешний по умолчанию; агент не выбирает)

**Правила:**

1. Файл создаётся в шаге 0 и обновляется после каждого шага, а не в конце сессии.
2. Если файл не обновлялся больше недели, агент при запуске спрашивает, продолжаем ли прежний шаг, а не начинает новый.
3. Режим «только локально» и контур меняет человек; агент их только читает и сообщает.
