# Целевые люди

**Куда:** скопировать в `workspace/people.md` и заполнять копию. Нужно 30–50 строк: из списка в разговор переходит малая часть.

| # | Кто | Сегмент | Почему он | Гипотеза проблемы | Чем полезен я | Точка входа | Канал | Статус | Следующая дата |
|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | нет входа | |

**Статусы:** `нет входа` → `есть вход` → `написал` → `ответил` → `разговор назначен` → `состоялся`.

## Правила

1. Без точки входа строка не считается готовой: нужен или тот, кто представит, или место, где пересечётесь.
2. «Чем полезен я» заполняется до сообщения, а не после: иначе разговор превращается в просьбу.
3. Персональные данные ограничены ролью и сегментом; телефоны и адреса в файл не пишутся.
4. Строка без статуса живёт не больше недели: либо действие, либо причина, почему нет.
