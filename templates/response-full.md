# Заготовка ответа на полный запрос

**Куда:** скопировать в `workspace/responses/<id>.answer.md` (у проекта — в его внутренней папке ответов); заготовка создаётся вместе с запросом, на каждый пакет своя.

**Проверка:** `python scripts/verify_research.py` — все `Q` запроса отвечены, обязательные разделы на месте, в каждом блоке есть ссылка или белое пятно, полнота проверяется по каждому каналу.

**Идентификатор запроса:** `req_XX_full`
**Файл запроса:** `workspace/requests/req_XX_full.md`
**Дата получения:** ГГГГ-ММ-ДД
**Каналы:** минимум два независимых (Perplexity / Qwen / Google / другой)
**Кто запускал:** ____
**Пакет:** N из M
**Кода нет:** да / нет (код и псевдокод в ответ не входят; если исполнитель прислал код — он не засчитывается, нужна ссылка и описание словами)
**Статус обработки:** (принят / отклонён / в очереди — заполняет агент после разбора; принят и отклонён уезжают в архив)

> Заполняется по фактам из ответа сервисов. Ничего не досочиняется. Задача ответа — **релевантные источники и алгоритмы словами**, без кода. Расхождение каналов не сглаживается, а показывается.

## Правила заполнения

1. Каждый факт — со ссылкой и датой. Ссылка без даты считается неполной.
2. **Код не принимается:** ни фрагменты, ни псевдокод, ни «пример реализации». Допустима ссылка на код как на источник + описание словами.
3. Алгоритм описывается шагами на естественном языке: вход, шаги, выход, границы применимости.
4. Два канала сверяются по идентификаторам: совпало — факт, разошлось — расхождение с обоими источниками.
5. Белое пятно подтверждается описанием поиска (каналы, формулировки, дата), а не «не нашлось».
6. Пропущенный идентификатор = неотвеченный вопрос.
7. Последняя строка ответа: «Чего найти не удалось: …».
8. Полнота проверяется по каждому каналу: `python scripts/verify_research.py`.
