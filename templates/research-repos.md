# Найденные решения под задачу

**Куда:** скопировать в `workspace/research/repos.md`. Заполняется мета-навыком `m1-repo-search`: сначала операция, потом средства.

## Задача

```
вход: что есть на руках
операция: что надо сделать
выход: что должно получиться
ограничения: локально или облако, бюджет, язык, объём, лицензия
```

## Кандидаты

| # | Репозиторий или инструмент | Адрес | Лицензия | Последний коммит | Размер | Стек | Локально | Тесты | Что проверил в файлах |
|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | |

## Решение

| Решение | Кому | Почему | Кто решил | Дата |
|---|---|---|---|---|
| взять как зависимость / взять как приём / отклонить | | | (заполняет человек) | |

## Правила

1. **Нет ссылки — нет находки.** Адрес и дата обязательны.
2. **Витрина не равна содержимому:** 2–3 заявления из описания проверяются по файлам; что не проверено — помечается.
3. **Отклонённое не удаляется:** причина отказа остаётся, иначе через месяц список всплывёт заново.
4. **Чужой код в набор не переносится:** берём приёмы и ссылки, а не файлы.
5. Пять ссылок с причиной лучше тридцати без причины.
