# Сырые ответы внешнего исследователя

Сюда попадают ответы, которые пришли не по нашему шаблону: статьи, отчёты, выгрузки дип-ресёрча без идентификаторов вопросов.

**Зачем отдельная папка.** Проверка полноты (`scripts/verify_research.py`) сверяет ответ с запросом по идентификаторам `Q1.1`. Файл без идентификаторов в общей папке она считает сломанной декларацией — и правильно: смешивать два формата нельзя.

**Что с ними делать:**

1. Прочитать и вытащить факты со ссылками и датами.
2. Каждый факт проверить: ссылка живая, дата есть, цифра действительно про то, о чём заявлено. Непроверенное в карточку не идёт.
3. Собранные факты выжать в карточку `knowledge/02_external/` по шаблону `templates/knowledge-card.md` и зарегистрировать в `knowledge/INDEX.md`.
4. Если по теме есть наш запрос — сопоставить факты с его вопросами и отметить, на какие `Q` они отвечают.
5. Оригинал остаётся здесь как след: он не превращается в базу, в базу идёт только выжимка.

**Уровень:** `[внешнее]`. Валидацией не является ни при каких условиях.
