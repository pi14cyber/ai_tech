# Ответы внешнего исследователя

Сюда складываются ответы на запросы из `pres/draft/requests/`. Имя файла: `<имя запроса>.answer.md`, например `req_00_stream.answer.md`.

**Ответы не по шаблону** (статьи, отчёты, выгрузки без идентификаторов) кладутся в `raw/` — там описано, как их обрабатывать. В общую папку их класть нельзя: проверка полноты считает файл без идентификаторов сломанной декларацией, и это верно.

**Как заполнять:** копировать `templates/research-response.md`, а не писать с нуля: в шаблоне уже расставлены блоки по идентификаторам вопросов.

**Как проверять полноту:**

```
python scripts/verify_research.py
```

Скрипт сверяет ответ с запросом по идентификаторам и сообщает:

- какие вопросы остались без ответа;
- есть ли идентификаторы, которых нет в запросе;
- есть ли обязательные разделы (факты за, факты против, белые пятна);
- в каждом ли блоке есть ссылка или пометка белого пятна.

Коды возврата: `0` — всё сходится или ответов ещё нет; `1` — ответ неполный; `2` — сломан запрос.

**Правило:** неотвеченный вопрос не додумывается. Он либо возвращается в очередь запросов, либо помечается белым пятном с указанием, где искали.
