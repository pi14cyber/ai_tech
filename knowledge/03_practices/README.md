# Приёмы и рецепты

Сюда попадают работающие приёмы: форматы артефактов-предлогов, удачные формулировки слепых запросов, способы замера рутины.

**Основание для добавления:** приём сработал хотя бы один раз в живом прогоне. Не «звучит разумно», а «сработало и вот на чём».

**Обезличивание обязательно:** никаких имён, компаний и личных данных. Личные записи живут в `workspace/memory/`.

**Уровень:** `[база]` для наших приёмов, `[внешнее]` если приём взят из чужого опыта со ссылкой.
