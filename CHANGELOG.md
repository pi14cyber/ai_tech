# История версий

Формат: версия — дата — что изменилось. Версия ставится тегом на коммит в `main`; отдельных веток набор не ведёт, `main` всегда рабочая.

## v0.2.3 — 20.10.2026 — сеть только через человека

- Канон: агент **не выполняет сетевых запросов** — ни поиска, ни браузера, ни API.
- Разрешено: локальный поиск по файлам репозитория, `workspace/` и клонов; по сети — только **составление файла запроса** по шаблону.
- Отправляет запрос человек через внешний сервис; ответ возвращается в `workspace/responses/inbox/` и разбирается локально.
- Запрос не исполнен — ворота предвалидации **заблокированы**, задание остаётся в очереди; «поищу сам» запрещено.
- В шаблонах запросов поле «Исполнитель запроса»; проверка `verify_consistency.py` следит за каноном и полями.

## v0.2.2 — 20.10.2026 — исследование только через внешние сервисы

- Канон в `AGENTS.md`: исследование — только через внешние сервисы, на 100%; собственный поиск агента, браузер и память модели каналом не считаются.
- Нет работающего сервиса — нет находки: задание в очередь, ворота предвалидации **заблокированы**, а не пройдены.
- Правило продублировано там, где применяется: навык предвалидации, поиск готовых решений, методика, запуск (`START.md`), словарь.
- В шаблонах запросов появились поля «Внешний сервис» и «Сервис проверен».
- Машинная проверка `verify_consistency.py` следит, чтобы канон и поля не исчезли.

## Правила версий

1. Одна пачка правок — один коммит с понятным сообщением; сразу `git push`.
2. Крупная веха — аннотированный тег: `git tag -a v0.3 -m «что именно»`.
3. Отчёты аудита и субагентов коммитятся отдельным коммитом, чтобы было видно, что правка основана на находке.
4. В историю не попадают: `workspace/` (данные человека), `internal/research/` (клоны), `runs/` (прогоны), каталоги оболочек.
5. Проверка перед коммитом: `python scripts/verify.py` — код 0.
